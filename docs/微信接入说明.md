# 微信接入说明

- 客户提供小程序开发权限、真实 AppID/密钥；密钥只配置到 Java 后端，禁止放在小程序源码中。
- 小程序后台配置 request、uploadFile、downloadFile 合法域名、服务类目和隐私保护指引，并添加客服人员。
- 后端配置 `WECHAT_APP_ID`、`WECHAT_APP_SECRET`、实际可用的 `CUSTOMER_TEMPLATE_ID`，总部后台填写真实模板字段映射。
- 用户主动订阅才登记可用次数；确认、改约、取消和到店提醒按授权条件发送，不能承诺无限推送。
- 已认证服务号接入门店管理员通知，后台按店绑定一名接收人；不依赖企业微信群通知。
- 正式验收包括真实微信登录、隐私授权、提交待确认、门店处理、客户状态、客服会话、订阅消息及服务号通知。

完整 [部署与账号条件](https://github.com/Ghostisme/yuhetang-miniprogram-backend/blob/main/docs/部署和微信接入.md) 由后端仓库统一维护。当前原生页面及控制器已经本地检查；客户 AppID 下的官方编译、真机和真实消息送达需在客户环境验收。
