# 微信接入说明

- 客户提供小程序开发权限、真实 AppID/密钥；密钥只配置到 Java 后端，禁止放在小程序源码中。
- 小程序后台配置 request、uploadFile、downloadFile 合法域名、服务类目和隐私保护指引，并添加客服人员。
- 后端配置 `WECHAT_APP_ID`、`WECHAT_APP_SECRET`、预约处理 `CUSTOMER_TEMPLATE_ID` 和到店提醒 `CUSTOMER_REMINDER_TEMPLATE_ID`；两类模板分别维护字段映射，并由 API 提供当前模板 ID。
- 客户从“我的预约”、预约提交或在线咨询进入微信登录页；阅读协议并主动同意后，Taro `login` 将一次性 code 交给 `/api/auth/wechat`，沿用原客户身份和业务数据。拒绝或暂不登录仍能浏览公开内容。不会通过 `getUserProfile` 取得头像昵称，也不把手机号获取作为客户登录的前提。
- 旧版静默登录态在新版首次使用时重新确认，成功后可保留登录；退出或 401 会隐藏个人数据，并提示重新登录。小程序登录、预约资料确认、微信隐私授权和订阅消息授权分别处理，不以其中一项代替其他授权。
- 原生客服回调单独使用 `https://booking.hetuonian.cn/api/wechat/customer-service`，配置 Token 和 EncodingAESKey，采用安全模式；后端配置 `WECHAT_MESSAGE_TOKEN`、`WECHAT_MESSAGE_AES_KEY`。业务 API 当前使用 `https://mp-admin.hetuonian.cn`，管理后台为该域名下的 `/admin`；request 合法域名应包含这个业务 API 域名。回调域名当前仅转发客服回调。
- 首页、养护详情、门店详情、预约、我的预约和咨询页提供原生 `button open-type="contact"`；直接打开微信客服，不依赖本系统登录或在线聊天接口。旁边的“在线咨询”保留项目自有聊天页；本地 H5 可以联调在线咨询；生产 H5 当前没有客户登录，客户咨询和原生对话请使用微信小程序。
- 原生按钮的 `session-from="yht-store:门店ID"` 只携带公开门店信息，空 ID 表示总部。服务端在验签、解密及校验 AppID 后，从微信进入事件读取门店，客户身份仅取自微信回调。切换门店后旧店保留历史但不能继续回复该客户。旧版随机入口仍兼容。
- 在线客服和原生微信会话在管理后台“客户沟通”分渠道接待；微信渠道按官方回复窗口/配额发送。外部客服工具发出的消息不自动同步回后台。
- 客户点击“提交预约申请”或“提交改约”时直接请求两个提醒模板的微信原生授权；拒绝或关闭不阻断预约。“我的预约”不提供单独的订阅按钮、设置入口或授权次数。只有本次原生授权实际同意的模板才登记可用次数；确认、改约、取消和到店提醒按授权条件发送，不能承诺无限推送。
- 已认证服务号接入门店管理员通知，后台按店绑定一名接收人；不依赖企业微信群通知。
- 正式验收包括真实微信登录、隐私授权、提交待确认、门店处理、客户状态、客服会话、订阅消息及服务号通知。

完整 [部署与账号条件](https://github.com/Ghostisme/yuhetang-miniprogram-backend/blob/main/docs/部署和微信接入.md) 由后端仓库统一维护。当前客户端为 Taro + React + TypeScript；本地执行 `npm run check:mini`、`npm run build:weapp` 和 `npm run build:h5`。微信开发者工具读取 `dist/weapp/`；客户 AppID 下的真机和真实消息送达仍需在客户环境验收。

本轮功能的权限、窗口和接口详见 [客服与门店品项接入](https://github.com/Ghostisme/yuhetang-miniprogram-backend/blob/main/docs/客服与门店品项接入.md)。

原生客服官方说明：[button](https://developers.weixin.qq.com/miniprogram/dev/component/button.html)、[小程序客服机制](https://developers.weixin.qq.com/miniprogram/dev/framework/open-ability/customer-message/customer-message.html)、[接收消息与 SessionFrom](https://developers.weixin.qq.com/miniprogram/dev/framework/open-ability/customer-message/receive.html)。
