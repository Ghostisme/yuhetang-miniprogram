# 客服授权与身份关联

适用入口：底部客服、门店联系菜单、在线咨询和微信原生客服。

## 客户操作

1. 点击在线咨询或微信客服。未登录时，先通过现有微信登录流程登录。
2. 未完成资料时，进入客户资料页，填写姓名或称呼，勾选资料用途同意，再点击“微信授权手机号并保存”。手机号通过微信原生授权按钮取得，不允许手填手机号代替授权。
3. 服务端保存成功后，在线咨询建立当前门店会话。微信客服入口准备完成后，点击微信客服按钮打开微信原生窗口。
4. 已完成上述资料的客户直接咨询；拒绝授权或资料读取失败时不创建客服会话，仍可电话联系门店。

客服资料表单没有“保存称呼”跳过按钮。仅填写姓名、勾选同意不会开放对话；H5 不提供手填手机号代替微信授权。已有微信授权手机号但缺少姓名或用途同意时，可点击“保存资料并开始咨询”，无需重复授权手机号。普通个人资料页仍支持单独保存称呼，但不会因此获得客服访问权限。

姓名或称呼由客户填写，不代表实名认证。微信手机号属于单独授权，与微信登录不是同一次授权。

## 后台可见内容

客户沟通的会话列表和详情显示客户姓名、微信授权手机号、会员或非会员状态，并支持按手机号搜索。会员状态继续使用门店核实维护的档案，不通过填写姓名或手机号自行升级会员。来源中包含大众点评时显示相应标识。

旧匿名会话保留历史记录，但不能接入或继续回复；客户用同一个小程序微信账号完善资料后，按该账号的 OpenID 关联档案。正在接待的历史会话仍允许原接待人结束或退回等待。

## 服务端校验

- `/api/me/chats`、`/api/me/chat/entry`、会话读取、发送和重新咨询都要求当前登录账号有姓名、已验证手机号及资料同意记录。
- 微信原生回调通过签名/解密校验后，以微信回调中的 OpenID 查询当前小程序客户账号。未完成授权时记录 `PROFILE_REQUIRED` 诊断结果，返回正常回调确认，不保存匿名会话、消息或回执。
- `SessionFrom` 使用服务端签发的临时不透明标识，不包含姓名、手机号或登录凭证，也不能代替身份授权。
- 后台读取客户资料保留原有门店权限；客户端聊天接口不返回后台客户档案信息。

## 发布与验收

本功能需要更新 Java 后端、管理后台前端及小程序代码。先更新后端和后台，再用本次 `dist/weapp` 上传体验版，完成手机测试后发布；后端更新不会使旧体验版自动升级。原有 Token、AESKey、AppSecret 不因本功能变更而重置。

本地检查：`npm run check:mini`、`npm run build:h5`、`node tools/verify-chat-identity.mjs`、`npm run build:weapp`。Java 使用隔离测试数据库运行 Maven 测试；管理后台运行构建及客服页面回归测试。

手机验收：新客户未登录不能对话；只登录不能对话；仅保存称呼不能对话；拒绝手机号不能对话；授权成功后在线咨询和微信客服都能收发，后台姓名手机号对应一致；会员与非会员账号分别检查，门店账号不得看到其他门店档案。退出登录后应立即关闭发送能力，重新进入必须再次核对当前账号资料。

微信自身已有的原生客服窗口不由本项目控制关闭；本项目会阻止未授权账号进入新入口，并在回调与回复端执行授权校验。真实微信手机号授权与消息送达仍需手机及已更新服务器联合验证。
